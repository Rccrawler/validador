## ✨ ¿Qué hace?

**Validador** es una herramienta ligera en Java que analiza y corrige tus textos en español directamente en tu máquina:

- ✅ **Corrección ortográfica** — detecta y sugiere correcciones de faltas
- ✅ **Orden de frases** — reorganiza estructuras gramaticales mal construidas
- ✅ **100% offline** — sin APIs externas, sin enviar tus datos a ningún servidor
- ✅ **Gratis para siempre** — sin planes de pago ni límites de uso
- ✅ **Portable** — distribuido como `.jar`, funciona en cualquier sistema con Java
